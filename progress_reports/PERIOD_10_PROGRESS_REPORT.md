### Project Summary
**AI CRM Call Agent App** is a complete end-to-end system that:
1. **Monitors** all phone calls on Android silently in background
2. **Logs** call metadata (caller, duration, time, type) locally
3. **Syncs** data to PostgreSQL CRM database via REST API
4. **Analyzes** calls using AI/LLM (sentiment, summary, action items)
5. **Displays** insights in a clean Flutter mobile dashboard

**Lines of Code:** ~8,000+ across Kotlin, Dart, Python  
**Technologies:** Flutter, Kotlin, Python FastAPI, PostgreSQL, OpenAI API
